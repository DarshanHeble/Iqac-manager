The worklog records faculty activity across the academic year. Entries are grouped by activity type and reviewed by the IQAC coordinator before the department's consolidated report is submitted.

Each department reports against a fixed set of criterion numbers, so entries from different years can be compared directly.

Quality assurance is a continuous process, not an annual exercise.

Definitions

Academic Year
The period from 1 June to 31 May, matching the university calendar.
Cycle
The academic year an entry belongs to. Entries cannot be moved between cycles.

Code

The API is reached at /api using the signed session cookie. A typical request is GET /api/entries?cycle=2025-26, and a full listing uses:

  "entries": 247,
